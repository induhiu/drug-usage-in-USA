# Analysis of Drug Usage among various age groups in the United States

## Overview
This repository contains the code, data pipelines, and final analytics report for Boston University's CS544 - Foundations of Analytics. The rendered HTML report includes the complete findings, visualizations, and statistical analysis.

## Repository Structure
- `index.html` — Main compiled analytics report hosted via GitHub Pages
- `drug-use-by-age.csv` — Dataset used in the analysis
- `CS544Final_Nduhiu.Rmd` — R Markdown script (source code)
